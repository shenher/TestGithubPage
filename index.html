關於我

我叫張軒赫，畢業於中原大學資訊工程系，目前在德蒙資訊管理顧問擔任全端工程師，累積了六年多的開發經驗，主要工作內容是企業系統的維護與新功能開發，涵蓋前端網頁、後端邏輯與資料庫設計。

在工作過程中，我養成了一個習慣——遇到重複性的人工作業，會試著思考有沒有辦法用程式來減少手動的部分。這不一定每次都能做到，但這樣的想法讓我在面對問題時，比較不容易只停留在「解決當下」，而是會多想一步。

這幾年參與的專案大小不一，從日常的系統維護、獨立開發小功能，到加入較大規模的專案負責部分模組，每個階段學到的東西都不太一樣。帶過小組成員之後，也更清楚自己在哪些技術細節上的掌握還不夠深，這讓我對自身能力的認識相對務實。

技術上目前主要熟悉 ASP.NET（WebForm 與 Core MVC）、C#、MSSQL，也有第三方 API 串接與 Azure DevOps 的使用經驗。前端部分以 jQuery 為主，較為基礎，這一塊是我自己知道相對薄弱的地方。

自行購買網域(cloudflare)，嘗試幫我老婆撰寫店面形象官網，過程知道了如何申請設定中華電信實體ip，以及修改家中路由器的port forward，和程式碼中監聽的port號，這三者的對應設定，並成功用自家電腦架設網站，也大致學會基本的cloudflare防火牆和網站憑證設定

目前希望能找到一個開發環境較為穩定、有機會接觸不同類型需求的團隊，持續在 .NET 相關技術上累積深度，也希望能在新的環境中學習更完整的系統設計或雲端應用的實務經驗。
